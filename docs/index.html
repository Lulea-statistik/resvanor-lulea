Så ska tidsserierna läsas

A = samma fråga/svarsskala. B = språkligt ändrad men semantiskt samma. C = samma fenomen men kräver omkodning eller metodharmonisering. D = inte jämförbar.

Direkt jämförbar används när definition och huvudupplägg bedöms tillräckligt lika. Jämförbar med metodreservation används när indikatorn fortfarande är analytiskt användbar men nämnare, frågeformulering, bearbetning eller undersökningssituation har förändrats.
