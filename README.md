# resvanor-lulea

Interaktiv GitHub Pages-webbplats för harmoniserade resvaneindikatorer i Luleå 2000–2025.

## Publicering
GitHub Pages är konfigurerad från `main/docs`.

## Struktur
- `docs/index.html` – webbgränssnitt
- `docs/app.js` – filter, diagram och tabell
- `docs/styles.css` – layout och responsiv design
- `docs/data/harmonized_rvu.csv` – harmoniserat kärnregister

## Jämförbarhet
Datapunkter klassas som:
- **direct** – direkt jämförbar
- **reservation** – jämförbar med metodreservation

Saknade eller ännu ej verifierade värden uppskattas inte.
